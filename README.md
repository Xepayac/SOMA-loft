# SOMA-loft

Static website for [SOMA-loft.com](https://soma-loft.com).

A hand-built static site — a single `index.html` plus an `assets/` directory
(styles, images) and a `sitemap.xml`. No build step: deploy by serving the
repository root.

## Structure

- `index.html` — the single-page site
- `assets/` — styles, images, and other static assets
- `sitemap.xml` — sitemap for search-engine indexing
